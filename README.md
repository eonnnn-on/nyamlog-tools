# 냠로그 미니 도구 (nyamlog-tools)

블로그·스레드에 링크로 걸어 쓰는 무료 웹 도구 모음입니다. 설치 없이 브라우저에서 바로 동작합니다.

| 도구 | 설명 | 바로가기 |
| --- | --- | --- |
| 연말정산 미리보기 계산기 | 총급여·기납부세액·카드·주거·세액공제를 넣으면 결정세액 산출 과정과 예상 환급/추납액, 절세 팁까지 계산 (2026년 귀속 기준) | [`/tax-calc/`](https://eonnnn-on.github.io/nyamlog-tools/tax-calc/) |
| 4조 2교대 근무 달력 | 주간 → 야간 → 비번 → 휴무 순환을 월간 달력으로 표시, 다음 휴무 카운터, 날짜별 메모(브라우저 저장), 홈 화면 앱 지원 | [`/shift-calendar/`](https://eonnnn-on.github.io/nyamlog-tools/shift-calendar/) |

## 구성

```
tax-calc/index.html        연말정산 미리보기 계산기 (단일 파일, 빌드 없음)
shift-calendar/index.html  4조 2교대 달력 (단일 파일)
shift-calendar/sw.js       오프라인 캐시
shift-calendar/manifest.json
icons/                     앱 아이콘
```

의존성·빌드 과정이 없습니다. HTML 파일을 고치면 그대로 반영됩니다.

## 개인정보

계산기와 달력 모두 입력값을 서버로 보내지 않습니다. 달력 메모는 `localStorage`에만 저장되어
기기를 떠나지 않습니다. 저장소 코드에는 개인 식별 정보가 들어 있지 않습니다.

## 기준

- 세액 계산: 국세청 연말정산 안내(2026년 귀속), 소득세법 제47조·제55조·제59조·제59조의4, 조세특례제한법 제58조·제95조의2·제126조의2
- 4대보험 요율(2026년): 국민연금 4.75%, 건강보험 3.595% + 장기요양(건강보험료의 13.14%), 고용보험 0.9% (근로자 부담분)
- 교대 순환: 2026-11-08 주간 기준, 주간 → 야간 → 비번 → 휴무 4일 순환 (주간 08:30~18:00, 야간 17:30~익일 09:00)

계산 결과는 참고용이며 최종 금액은 회사 연말정산·홈택스에서 확정됩니다.
